# Contributing / Katkıda bulunma

Open an issue with board, core version, motor driver, IMU, control loop interval and steps to reproduce. For changes, submit a pull request with a host regression test. Avoid changing control equations without baseline comparisons. Report physical tests separately from simulation. Never publish Wi-Fi credentials or private logs.

Use a supported stand and emergency motor cutoff for first tests. A passing compilation is not proof of safe physical operation.
